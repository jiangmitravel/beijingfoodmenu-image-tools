# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.2.0] - 2026-01-09

### Added
- **ZIP Download Mode**: Package all processed images into a single ZIP archive
- **Dynamic Height Calculation**: Real-time height preview in Fixed Width mode
- **File Naming Options**: Three flexible naming modes (Prefix, Suffix, Number)
- **Privacy Protection**: Option to remove EXIF metadata from processed images

### Features
- Batch image processing with drag-and-drop support
- Quality adjustment (1-100%)
- Smart resizing options (percentage and fixed width)
- Format conversion (JPEG, PNG, WebP)
- Modern, responsive interface
- Pure client-side processing (no server upload)
