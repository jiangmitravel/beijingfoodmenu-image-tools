# Icon Placeholder

This directory should contain the extension icons in the following sizes:

- **icon16.png** - 16x16 pixels (toolbar icon)
- **icon48.png** - 48x48 pixels (extension management page)
- **icon128.png** - 128x128 pixels (Chrome Web Store)

## Design Guidelines

- Use the Beijing Food Menu brand colors (purple gradient: #667eea to #764ba2)
- Include a recognizable image/photo icon
- Ensure icons are clear and visible at all sizes
- Use PNG format with transparency

## Creating Icons

You can create icons using:
1. Image editing software (Photoshop, GIMP, etc.)
2. Online icon generators
3. The `generate_image` tool to create initial designs

## Temporary Solution

Until proper icons are created, you can use placeholder icons or the website favicon scaled to appropriate sizes.
